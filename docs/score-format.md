# 简谱文本格式

内置曲谱、手动录入、大模型识谱，**都用这一种格式**。解析器（`parser/`）把它编译成 [IR](score-ir.md)，App 读 IR。

## 原则

- **像手抄简谱**：人能直接敲，大模型容易输出
- **只用 ASCII**：不用切输入法
- **严格、无歧义**：一份谱只有一种结果；错误一次报全，每条带 `行:列`，可以直接交回大模型修改
- **能扩展**：新记号加进来，旧谱照样能用

## 示例

```text
title: 茉莉花
key: 1=F
time: 2/4
tempo: 72

3 3_ 5_ | 6_ 1'_ 1'_ 6_ | 5 5_ 6_ | 5 - |
3 3_ 5_ | 6_ 1'_ 1'_ 6_ | 5 5_ 6_ | 5 - |]
```

## 谱头

文件开头连续的 `名字: 值` 行；第一行不是这种格式的，就是谱面开始。

| 字段 | 必填 | 写法 | 说明 |
| --- | --- | --- | --- |
| `key` | 是 | `1=D` `1=bB` `1=#F` | 调号 |
| `time` | 是 | `2/4` `6/8` `free` | 拍号；分母 2、4、8、16；`free` 是散板 |
| `tempo` | 是 | `72`、`4.=60`、`8=144` | 每分钟拍数；不写单位就是四分音符；20–300 |
| `title` `composer` | 否 | 文本 | 曲名、作者 |
| `fingering` | 否 | `5,` `2,` `6,` | 筒音作几，带八度点；建议值，设置里选的优先 |
| 其他 | — | — | 警告并忽略 |

## 音和休止

音的写法顺序固定：`升降号? 音 八度点* 减时线* 附点* 技巧*`

| 部分 | 写法 | 例子 |
| --- | --- | --- |
| 升降号 | `#` `b` | `#4` `b7`，**只管这一个音** |
| 音 | `1`–`7` | `5` |
| 八度点 | `'` 高、`,` 低，每个一个八度 | `1'` `5,` `6,,` |
| 减时线 | `_`，每条时值减半 | `5_` `5__` |
| 附点 | `.`，最多两个 | `5.` `5_.` |
| 技巧 | `@名字` 或 `@名字(音)` | `5@tr` `2@tr(4)` |

- **休止**：`0`，可以带减时线和附点；长休止写 `0 0`，不用 `-`；只能带 `@yanchang`
- **增时线**：单独的 `-`，每个加一拍，只能跟在不带减时线、不带附点的音后面。`5 -` 二分、`5 - -` 附点二分、`5 - - -` 全音符

时值（单位：四分音符）：

```text
时值 = (1 / 2^减时线数) × (2 − 1 / 2^附点数) + 增时线数
```

## 小节

| 写法 | 含义 |
| --- | --- |
| `\|` `\|\|` `\|]` | 小节线、双小节线、终止线 |
| `[time 3/4]` `[key 1=G]` `[tempo 96]` | 写在小节开头：换拍号、换调、换速度 |
| `[section 引子]` | 段落：【一】、引子、散板、尾声……，显示时另起一行 |
| `// …` | 注释，到行尾 |

- 每小节时值等于拍号；**第一小节（弱起）和最后一小节可以不满**；散板（`free`）不检查
- **换行**只能跟在小节线后面，表示原谱在这里分行
- 谱面必须以小节线结束

## 笛子技巧

纸上本来是字母的照写，其余用拼音；一律小写。括号里的音和谱面写法一样，比如 `1'`、`#4`。

| 写法 | 技巧 | 写法 | 技巧 |
| --- | --- | --- | --- |
| `@t` `@k` | 吐音的"吐""苦"，每个音标一个：单吐 `t`，双吐 `t k`，三吐 `t t k` | `@qingtu` | 轻吐 |
| `@baochi` | 保持音 | `@qiang` | 强音 |
| `@tr` | 颤音 | `@tr(4)` | 多度颤音：颤到 4 |
| `@shanghua` `@shanghua(3)` | 上滑音（从 3 滑上来） | `@xiahua` `@xiahua(5)` | 下滑音（从 5 滑下来） |
| `@yuanhua(5)` | 圆滑音：3→5→3 | `@duo(1')` | 剁音：从高音 1 剁下 |
| `@die` | 叠音 | `@da` | 打音 |
| `@bo` `@xiabo` | 上波音、下波音 | `@feizhi` | 飞指 |
| `@huashe` | 花舌 | `@zhizhen` | 指震音 |
| `@qizhen` | 气震音 | `@fuzhen` | 大腹震音 |
| `@fan` | 泛音 | `@rou` | 揉音 |
| `@hou` | 喉音 | `@yanchang` | 延长记号 |

| 写法 | 含义 |
| --- | --- |
| `{6}5`、`{65}5` | 前倚音，紧贴主音前面；可以多个音 |
| `5{6}` | 后倚音（赠音），紧贴主音后面 |
| `(1 2 3)` | 连线：线内不吐；**两个相同的音**连起来就是延音线 `(5 \| 5)` |
| `v` `V` | 换气、循环换气，单独写在两个音之间 |

## 暂不支持

| 记号 | 现在的处理 |
| --- | --- |
| 反复 `\|:` `:\|`、房子 `[1.]` `[2.]` | 警告，按顺序演奏一遍 |
| 连音（三连音等）、力度、表情文字、渐快渐慢 | 尚无写法，以后加 |
